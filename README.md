# Pixel Gallery – Responsive Image Gallery

A modern, responsive image gallery website developed using HTML, CSS, and JavaScript as part of the **CodeAlpha Frontend Development Internship – November 2026**.

## Project Overview

Pixel Gallery is a visually appealing photography gallery that allows users to explore beautiful photographs across different categories. It features a clean, warm interface with cream, yellow, and coral-red colors.

## Features

- Responsive image gallery layout
- 12 curated photography images
- Category-based image filtering
- Categories: Nature, Architecture, Animals, and Travel
- Full-screen Lightbox image preview
- Next and Previous image navigation
- Keyboard navigation using arrow keys
- Escape key to close the Lightbox
- Smooth hover effects and transitions
- Responsive design for mobile and desktop screens
- Dynamic image counter

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, animations, and responsive layout
- JavaScript – Gallery functionality and interactions

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Amirkhan786-coder/CodeAlpha_ImageGallery.git
   ```

2. Open the project folder:

   ```bash
   cd CodeAlpha_ImageGallery
   ```

3. Open `index.html` using VS Code Live Server or your web browser.

4. Explore the gallery and test its interactive features.
